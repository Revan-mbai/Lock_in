# Lock In — Focus & Break Suite

A warm, minimalistic study suite with automated focus and break timers. Five methods, each with
its own timer that keeps running while you switch tabs and survives a reload:

| Method | Focus | Break | Transition |
| --- | --- | --- | --- |
| Pomodoro Technique | 25 min | 5 min (15 min every 4th cycle) | Auto-shifts |
| Flowtime Technique | Flexible | 5–20 min, earned from how long you focused | You choose |
| 90-Minute Work Cycle | 90 min | 20 min | Auto-shifts |
| Time Boxing | Custom blocks | Built-in buffers | Auto-shifts |
| The 52/17 Rule | 52 min | 17 min | Auto-shifts |

Plus a procedural ambient sound generator (brown/pink/white noise, rain, waves, campfire, cafe,
alpha-wave drone — all synthesised in the browser, no audio files), a Zen mode, a daily focus
log, and offline support as an installable PWA.

## Run locally

**Prerequisites:** Node.js 20.19+ (or 22.12+)

```bash
npm install
npm run dev
```

The app opens on <http://localhost:3000>. No API keys, environment variables or backend are
required — everything runs client-side and all state is stored in the browser's `localStorage`.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the Vite dev server on port 3000 |
| `npm run build` | Production build into `dist/` (does not type-check — use `lint` for that) |
| `npm run preview` | Serve the built `dist/` locally |
| `npm run lint` | Type-check with `tsc --noEmit` |
| `npm run clean` | Remove `dist/` |

## Notes

- **Service worker.** `vite-plugin-pwa` generates and registers it at build time; it is disabled
  during development. Do not add a manual `navigator.serviceWorker.register` call — that
  registered a second worker in production and a stale cache-first one in development.
- **Web app manifest.** Generated by `vite-plugin-pwa` as `/manifest.webmanifest` and injected
  into `index.html`. Do not add a second `<link rel="manifest">`; browsers honour only the first.
- **Fonts.** Plus Jakarta Sans, Newsreader and JetBrains Mono are loaded in `index.html` and bound
  to Tailwind's `--font-sans` / `--font-serif` / `--font-mono` tokens in `src/index.css`. Tailwind
  v4 takes its font stacks from those tokens, so a font added to the HTML alone will not apply.
- **Icons.** The PWA icons, `apple-touch-icon.png` and `favicon.ico` in `public/` are generated by
  `node scripts/generate-icons.js`.
